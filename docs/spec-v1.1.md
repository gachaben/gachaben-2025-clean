🧭 1. 基本コンセプト

「勉強＝ガチャ＋バトル＋育成」で楽しく続ける学習アプリ。

学習 → ガチャ → 強化 → バトル のループで習慣化。
広告視聴によるリワード設計で、自然な収益モデルを構築。

v1.6では、“敵を倒す戦い”から“音で努力を奏でる体験”へ進化。
**チャレンジ問題でバトル券を集め、ドレミファソラシドを奏でて勝利する「努力型バトル」**を軸に統一。

🎵 2. 学習の三本柱（v1.6 再定義）
柱	名称	内容	主な報酬	備考
① 学習問題	Study	教科書準拠の基礎問題。単元進度に合わせて出題。	🎴 アイテムカード（昆虫・パンシリーズなど）	2か月ごとのシーズン構成。努力を「コレクション化」。
② チャレンジ問題	Challenge	難易度の高いスピード形式・応用問題。集中力を試す。	🧩 バトルカード（戦略用）
🎫 バトル券（Battle Ticket）	「挑戦＝バトルの準備」。努力が挑戦につながる導線。
③ バトルモード	Battle Challenge	バトル券を使ってCPUと対戦。正答で音符（ドレミ）を集める。	🎵 ドレミポイント（DP）
🎁 称号・ランキング報酬	努力の可視化。勝敗でDP加算（勝10 / 負5 / 復活+5）。
🎫 モード循環構造
学習問題 → チャレンジ問題（バトル券・カード獲得） → バトル → DP・称号アップ
　↑───────────────────────────────────────↓
　　　　　　努力（Study）→挑戦（Challenge）→成果（Battle）のループ

⚔️ 3. 新バトルシステム「ドレミチャレンジバトル」
🎮 概要

対戦相手：CPU（挑戦型・非PvP）

勝利条件：7音（ドレミファソラシド）を集める

難易度：Lv1 / Lv2 / Lv3（ユーザー選択）

出題範囲：Firestoreの学年・進度に連動

消費：1バトルにつき 🎫バトル券×1

再挑戦：バトル券が無い場合はチャレンジ問題 or 広告視聴で補充

🎫 4. バトル券（Battle Ticket）
項目	内容
入手方法①	チャレンジ問題の報酬（ドロップ率30〜50%）
入手方法②	リワード広告視聴（1本＝🎫×1）
所持上限	5枚
保存場所	users/{uid}/tickets
UI	右上またはバトル導入画面に🎫アイコン表示
消費処理	consumeTicket() 実行時に tickets--
🧠 5. 出題ロジック（Firestore連動）
const q = query(
  collection(db, "problems"),
  where("grade", "<=", user.grade),
  where("unit", "in", user.progress.math.completedUnits),
  where("level", "==", selectedLevel)
);


→ 学年・進度・難易度に応じた動的出題。

🏆 6. ドレミポイント（DP）
条件	DP
勝利（7音達成）	+10 DP
敗北	+5 DP
❤️ 復活カード使用	+5 DP（※これのみ。勝敗分に追加付与はしない）

📘 例

復活カードを使って勝利：10 + 5 = 15DP

復活カードを使って敗北：5 + 5 = 10DP

Firestore保存

users/{uid}/stats.doremiPoints
users/{uid}/stats.doremiRank

🎹 7. 称号（鍵盤ランク）
ランク	名称	必要DP
Lv1	リコーダー	0〜49
Lv2	オルガン	50〜99
Lv3	ピアノ	100〜199
Lv4	シンセサイザー	200〜299
Lv5	グランドマイスター	300〜

ランクアップ時に RankUpModal 発火（鍵盤発光＋音符演出）

🧩 8. バトルカード（戦略要素）
カード	効果	タイミング
🧠 選択肢カット	4択→3択	出題前
⏰ 時間延長	制限時間+5秒	出題直後
🔄 チェンジ	問題を再抽選	出題後
❤️ 復活	ミスしてもコンボ維持（自動）	自動発動
🌟 スタートブースト	開始時+2pt（ミ→ファから開始）	開始時

1バトルにつき3枚まで使用可（❤️復活は回数外）

Firestore：users/{uid}/battleCards.{cardId}: number

🎁 9. ランキング・報酬設計
項目	内容
集計対象	stats.doremiPoints（期間内増分ベース推奨）
表示例	🥇 はるかちゃん 1320DP／🥈 そうたくん 1190DP
報酬①	参加賞：🎫バトル券×5（全参加者）
報酬②	上位賞：プレミアガチャ券・限定称号「ドレミマスター」など
Firestore集計	Cloud Functions or 定期タスクで処理予定
🌈 10. 音符・演出統一システム
シーン	表現	演出
正解時	♩（NoteBurst）	ピコン音＋光エフェクト
進行ゲージ	7音（NoteTrackBattle）	ドレミファソラシド進行表示
勝利時	ドレミ音ループ＋虹エフェクト	「努力のメロディ」演出
プレミア報酬時	𝄞＋虹音符	ドレミ＋BGM付き祝福演出

🏁 バトルシステムv1.6まとめ

「バトル」は“競争”ではなく“努力の演奏”。
バトル券で挑戦し、ドレミポイントで努力を奏で、
鍵盤称号で自分の音を完成させる体験へ。
