⚠️ このドキュメントが唯一の基準仕様です。  
以降の企画・開発・Gitタグはこの内容に基づきます。

---

## 🧭 1. 基本コンセプト

「勉強＝ガチャ＋バトル＋育成」で楽しく続ける学習アプリ。  
学習 → ガチャ → 強化 → バトル のループを、“音符”という共通の言語で統一。  

音符は努力の証であり、成長・挑戦・成果のリズムを奏でる。  
v1.5では **「音符三系統ループ」** を正式採用。

---

## 🎼 2. 音符三系統ループ

| フェーズ | 音符の意味 | 7音達成時の報酬 | Firestore項目 | 主なUI | 備考 |
|-----------|-------------|------------------|----------------|--------|------|
| **① 学習問題（Study）** | 📖 知識の音 | 🎁 アイテムカードガチャ券 | `stats.studyNotes` | `<NoteTrackStudy />`（ピンク系） | 教科ごとに音色が異なる（国語＝木琴、算数＝ピアノ等） |
| **② チャレンジ問題（Challenge）** | 💪 努力の音 | 🎫 バトルチケット or バトルカード | `stats.challengeNotes` | `<NoteTrackChallenge />`（青系） | 難易度ごとに音符数が変動（Lv1=2音, Lv2=3音, Lv3=4音） |
| **③ バトル（Battle）** | 🏆 成果の音 | 🌈 ドレミポイント加算＋称号更新 | `stats.battleNotes` | `<NoteTrackBattle />`（虹色） | ドレミファソラシドで勝利演出＋DP獲得 |

## 🎶 3. 音符獲得ルール（難易度別）

| 問題タイプ | 難易度 | 音符加算数 | 平均獲得テンポ | 備考 |
|-------------|----------|--------------|----------------|------|
| 学習問題 | Lv1 | +2 | 約3問で7音 | 教科書準拠・練習用 |
| チャレンジ問題 | Lv2 | +3 | 約3問で7音 | バトル関連報酬ループ |
| チャレンジ問題（高難度） | Lv3 | +4 | 約2問で7音 | 短期集中型 |
| 特別イベント問題 | LvEX | +7 | 1問で7音確定 | プレミアチケット即獲得 |

## ⚙️ 4. Firestore 構造（統一仕様）

```js
users/{uid} {
  hearts: number,             // スタミナ
  tickets: number,            // バトルチケット
  stats: {
    studyNotes: number,       // 学習音符（0〜7）
    challengeNotes: number,   // チャレンジ音符（0〜7）
    battleNotes: number,      // バトル音符（0〜7）
    doremiPoints: number,     // ドレミポイント（ランキング用）
    doremiRank: string,       // 鍵盤称号
  },
}
