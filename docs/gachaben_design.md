## 2. 学習システム（❤制）
- ❤最大：5
- 問題を解くごとに ❤−1
- ❤回復方法：
  - 15分ごとに1回復
  - 広告視聴で全回復（MAX5まで）

---

## 3. ミッションとガチャ
### デイリーミッション
1. 教科書問題（1ステージ＝5問、全問正解でクリア）
2. プレイ時間5分以上
3. 計算・漢字・音読（いずれか1回でクリア）

### ガチャの種類
- ①1つずつクリア → **ノーマルガチャ**（B中心、A：5%、S：1%）
- ②2つずつクリア → **激熱ガチャ**（A中心、S：10%）
- ③3つずつクリア → **プレミアムガチャ**（S確定）

### ガチャ追加
- ガチャ後、**広告視聴で同レベル＋1回**おかわり可能（回数制限は後日調整）。

---

## 4. アイテムカードと進化
- アイテムランク：B / A / S
- 進化段階（5段階固定）：**優 → 王 → 極 → 龍 → 神**
- 進化方法：パワーアップガチャ券を使用
- UI：カード左上に称号バッジを重ね表示

## 5. バトルシステム（バトル券制）
- 1日の無料挑戦回数：**3回**（毎日リセット）
- バトル回復：**広告視聴で全回復（MAX3）**
- **仮想対戦**：Firebase上の他ユーザー（学年・進度が近い）をマッチングし、CPUがそのユーザーの傾向を模した挙動で解答。

### 5.1 フロー（ジャンケン → バトルガチャ → 出題）
1. **ジャンケン**：勝った側が「出題者」になる。
2. **バトルガチャ**：出題者は**バトル専用ガチャ**を1回回し、難問出現ブーストを抽選。
   - ガチャ結果は以下のいずれか：
     - **80%**：難問（レベル3）優先
     - **50%**：中庸
     - **30%**：安全寄り
3. **出題**：**出題者が過去に解いた問題**（＝武器）から、結果に応じた重みでランダム出題。
4. **解答判定**：相手（CPU）が**正解**→次のジャンケンへ／**不正解**→出題者の勝ち（ラウンド終了）。
5. **最大3ターン**：3ターンで決着がつかなければ**引き分け**。

> 判定ロジック：CPUの正誤は「対戦相手の履歴に基づく正答傾向」＋「問題難易度」の組合せで決定（詳細は実装段階で調整）。

### 5.2 問題難易度と抽選重み（例）
- 問題には **level: 1 / 2 / 3** を付与。
- バトルガチャ結果ごとの重み（例）：
  - **80%**：Lv3=80% / Lv2=15% / Lv1=5%
  - **50%**：Lv3=50% / Lv2=35% / Lv1=15%
  - **30%**：Lv3=30% / Lv2=40% / Lv1=30%
- **直近出題クールタイム**：同一問題は**連続出題しない**（新鮮さ確保）。  
  ※実装では「同一週に同カード3連続禁止」など軽い制約を想定。

### 5.3 バトルガチャ演出（共通筐体＋差別化）
- **筐体は通常ガチャと共通**（回る→出る→開く→ポン！）。
- **背景（壁紙）**：数字「80 / 50 / 30」がランダムに浮遊・点滅。
- **開封時**：カプセルが開き、**当選数字が飛び出す**。  
  - 80%：派手（炎・雷）／50%：中くらい／30%：控えめ
- 結果表示は**1秒程度**で即出題へ（テンポ重視）。

## 6. ランキングイベント（週末）
- **週次イベント**：月〜日で1サイクル。
- **平日**：その**日**に解いた問題のみが武器。
- **週末（土日）**：その**週**に解いた全問題が武器、**ポイント2倍**。
- 勝敗ポイント（例）：
  - 勝利：+30
  - 惜敗：+10
  - 敗北：+5
  - 引き分け：+1

### 報酬設計
- 1位：プレミアムガチャ券×5 ＋ 特別称号
- 2位：プレミアムガチャ券×3
- 3位：プレミアムガチャ券×2
- 上位1割：プレミアムガチャ券×1 ＋ 称号
- 参加賞（全員）：ノーマルガチャ券×1
- ※称号の中身は後日定義（期間限定 or 累積型）。

## 7. 広告収益導線
- ❤回復（広告で全回復）
- バトル回復（広告で全回復）
- ガチャおかわり（広告で＋1回）
- 週末イベント：**追加挑戦権**を広告で配布
- デイリーボーナス：広告視聴でボーナス（❤+1／バトル+1／ノーマルガチャ券）

> リワード広告：**最後まで視聴で報酬付与**（秒数はネットワーク依存、主に15〜30秒）。

10. 用語定義（ブレ防止）

❤：スタミナ。最大5。内部キー hearts。

バトル券：1日の無料挑戦回数。内部キー battleTickets（最大3）。

武器：ユーザーが解いた問題IDの集合。バトル出題の母集団。

問題レベル：level = 1/2/3（難→重みづけに使用）。

週：月曜00:00〜日曜23:59（Asia/Tokyo）。

11. クリティカル仕様（境界条件）

❤消費タイミング：問題の「解答確定」時に -1。

❤回復タイミング：lastHeartTick から 15分ごとに +1（MAX=5）。

広告回復：視聴完了イベント受信時に hearts=5。連打防止にクールダウン 10分。

直近出題クールタイム：同一問題は同セッションで連続出題禁止＋週末イベント中は同問題の再出現間隔=3問以上。

未成年配慮：広告はミュート解除不可・スキップ不可のリワード広告のみ。ペアレンタル同意（ToS/Privacyに明記）。

13. バトル出題ロジック（確定アルゴリズム）

武器母集団＝users/{uid}.solvedProblems。

バトルガチャ結果（80/50/30）→重みテーブルを選択。

weightedRandomPick(母集団, weights[level]) で1問選ぶ。

直前出題と同一IDはスキップ。

CPU正誤は「相手履歴の正答率×問題level×乱数」で判定（係数は環境変数で可変）。

14. ガチャ確率テーブル（ソースオブトゥルース）

ノーマル：B多め／A=5%／S=1%

激熱：A多め／S=10%

プレミアム：S=100%

テーブルは config/gachaTables.json に一元管理し、UI表示の文言もここから参照。

❤自動回復（クライアント共通関数）

export function computeHearts(now, lastTick, hearts) {
  if (hearts >= 5) return { hearts, lastTick };
  const minutes = Math.floor((now - lastTick) / 60000);
  const gained = Math.floor(minutes / 15);
  if (gained <= 0) return { hearts, lastTick };
  const nextHearts = Math.min(5, hearts + gained);
  const consumedMinutes = gained * 15;
  const nextTick = lastTick + consumedMinutes * 60000;
  return { hearts: nextHearts, lastTick: nextTick };
}


直近出題クールタイム（擬似コード）

function pickProblem(pool, weights, recentIds) {
  const candidates = pool.filter(p => !recentIds.includes(p.id));
  return weightedRandom(candidates, p => weights[p.level]);
}
