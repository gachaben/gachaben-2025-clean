# ⚔️ ガチャ弁アプリ構想ドキュメント v1.7b（バトル統合仕様）

🎵 **音符三系統ループ × バトル × プレミアムガチャ**  
「努力の音が、成果の音へ進化する」完全ループ構想。

---

## 🧭 1. 世界観と基本構造
「勉強＝ガチャ＋バトル＋育成」で続く学習ループ。  
学習 → チャレンジ → バトル → ガチャ → 成長。  
全てが“音符”でつながるリズム設計。

---

## 🎮 2. バトルの基本ルール
| 項目 | 内容 |
|------|------|
| 形式 | 7問制（4問先取で勝利） |
| 対戦 | 自分 vs CPU（AIシミュレーション） |
| 分野 | チャレンジ問題と共通（7教科・7分野） |
| 時間制限 | なし（思考重視） |
| 勝敗 | 4問取れば勝利確定（ファ到達で勝ち） |
| 表現 | 音符が1問ごとに点灯（ド→レ→ミ→ファ→ソ→ラ→シ→ド） |

---

## 🎫 3. バトルチケットシステム
| 要素 | 内容 |
|------|------|
| 名称 | バトル券 |
| 上限 | 7枚（全7色：ド・レ・ミ・ファ・ソ・ラ・シ） |
| 入手 | チャレンジ問題7音達成時に1枚配布 |
| 消費 | バトル1回につき1枚消費 |
| 特例 | バトル券がない場合、広告視聴で1回参加可 |
| 広告前特典 | 視聴でDP報酬2倍ブースト |

---

## 🏆 4. 勝敗報酬と進行
| 状況 | DP報酬 | 音符 | 備考 |
|------|---------|------|------|
| 勝利 | +10 DP | 勝利音符 +1 | 7音達成でプレミアムガチャ券獲得 |
| 敗北 | +5 DP | 敗北音符 +1 | 負けても努力記録として反映 |
| 復活カード使用 | 勝てば +10 / 負けても +5 DP | 再挑戦演出あり |
| バトル後広告 | 次戦DP2倍券を獲得可能 | |

---

## 🎵 5. バトル音符仕様（NoteTrackBattle）
| 表示 | 意味 |
|------|------|
| ド・レ・ミ・ファ | 4問先取で勝利確定（ファ＝勝ち演出） |
| ソ・ラ・シ・ド | 勝利後のボーナス音符（コンプリート時に虹色演出） |
| 全7音点灯 | 「ドレミファソラシド♪」再生 → プレミアムガチャ券配布 |

## 🪙 6. Firestore モデル（統合）
```json
users/{uid} {
  tickets: number,               // バトル券（最大7）
  stats: {
    battleNotes: number,         // バトル音符（0〜7）
    doremiPoints: number,        // DP（勝10 / 負5）
    doremiRank: string           // 鍵盤称号
  },
  lastBattleAt: Timestamp
}
7音到達時：
await updateNoteProgress(uid, "battle", +1);
if (battleNotes >= 7) handleReward("premium");
