1. 基本コンセプト

「勉強＝ガチャ＋バトル＋育成」で楽しく続ける学習アプリ。

学習 → ガチャ → 強化 → バトル のループで習慣化。

広告収益モデル重視（課金要素は最小限）。

ストーリーは軽い導入演出のみに留め、主軸は「3本柱」で構成。

2. 学習の三本柱
柱	内容	主な報酬
① 学習問題	教科書に沿った基礎問題	❤回復、ノーマルガチャ券
② チャレンジ問題	難問やスピード形式、報酬倍率UP	ガチャ券＋バトルカード
③ バトル問題	CPU対戦（ジャンケン→出題）	ポイント、称号、壁紙
3. ハート（❤）システム

最大5個

問題1問ごとに −1

10分で +1 自動回復

広告視聴で全回復（MAX5）

4. ログイン・時間ボーナス
条件	報酬
5日連続ログイン	Sランクガチャ確定
7日連続ログイン	プレミアムガチャ確定
1日5分プレイ達成	シリーズ別壁紙ガチャ（昆虫・パンなど）

💡 壁紙はシリーズごとに色違い／季節違いを用意。
集めることで「ホーム画面演出」が変化。

5. ガチャシステム

通常確率：当たり20％、ハズレ80％

広告視聴ガチャ：当たり50％

5連続ハズレ後：次は確定当たり（天井演出あり）

ガチャ実行時、「激アツ」「超激アツ」などの確率演出をランダム表示
（例：激アツ→50％、超激アツ→60％、通常→20％）

✅ 6. バトルカード（攻守兼用・5種）
カード名	攻撃時効果	防御時効果
知略カード	選択肢を1つ消す	相手の選択肢を1つ追加
スピードカード	タイマー短縮	タイマー延長
安定カード	1勝からスタート	1敗からスタート
１発逆転カード	負けていても次の問題で正解したら勝利	勝っていても次の問題で不正解なら負け
リトライカード	負け確定でも、追加問題で正解なら勝利	勝っていても追加問題で不正解なら負け

合計10パターンの戦略性。

バトル時にランダム所持カードを提示。

マックス5枚（1種類1枚）／1試合2枚まで使用OK。

✅ 7. バトルシステム（ジャンケン＋出題）

ジャンケン勝者が出題者（攻撃側）。

勝者が問題を出題し、敗者が解答。

敗者が正解 → 次のジャンケンへ進行。

敗者が不正解 → 出題者（攻撃側）の勝利。

5問しても勝負がつかない場合は引き分け。

CPUは過去の平均正答率を参照して行動。

勝利で 1音（♪）獲得。

将来的に、問題ジャンルごとに音階テーマを切り替える拡張も想定（例：理科＝低音系、国語＝柔音系）。

🎼 どれみ音システム（学習ロードマップ連動）
🌱 基本コンセプト

各 小単元クリアごとに「音符（ど・れ・み…）」を1音ずつ獲得。

進捗が音として積み重なり、学習の達成感をメロディで感じられる仕組み。

単元クリア時には短いメロディ（例：「ドレミファソラシド」）が流れる。

小2	国語	6単元	ド〜ラ	最後に「シ」で完結
小3	理科	8単元	ドレミファソラシド＋ドレ	以降ループも可
・・・	・・・	・・・	・・・	教科別ロードマップにも適用可能

第4章：音符システムによる世界観統一（v1.3拡張）
概要

ガチャ弁アプリ全体の報酬・演出・モチベーション設計を「音符」を中心に再構築。
学習行動・ログイン・稼働時間・報酬演出のすべてが、“音符が舞う”体験として統一される。
教育的没入感と自然な収益サイクルを両立させた、ガチャ弁の新基幹システム。

4-1. ログイン時のプレミアガチャ演出（入口体験）

初回ログイン時に「プレミアガチャチャンス」演出が発生。

音符の色と数で確率表示：

🎵20％＝単色音符（初日）

🎶40％＝カラフル音符（中間）

🌈100％＝虹色音符（7日目）

「動画視聴でガチャ解放」

外れても「もう一度動画視聴で再挑戦OK」

7回以内に必ず当たる累積確率型。

→ ログイン＝収益＋期待感の導線。

4-2. 稼働時間ボーナス（学習中報酬導線）

アプリ稼働5分ごとに音符が1つ舞う（最大7段階／35分）。

音符の色と舞い方が時間経過で変化：

5分＝単色音符がふわふわ

10分＝増える＋明るい色

35分＝虹色音符がパッと大量に舞う

下部ゲージがピコンピコン光って音符を蓄積。

ゲージをタップするとガチャ挑戦ページに誘導。

→ 勉強時間がそのままガチャ期待度に変わる。

4-3. 音符演出の統一設計

ログイン、稼働、問題正解、すべてに共通の「音符が舞う」演出。

色・形・動きで“報酬の期待度”を表現：

🎵単色音符＝低確率

🎶カラフル音符＝中確率

🌈虹色音符＝確定報酬

四分音符、八分音符など音符形状でも段階を表す構想。

→ 音でモチベを視覚化し、世界観を完全統一。

4-4. システム全体の報酬ループ
ログイン → 動画視聴 → 音符演出 → ガチャ
　↓
学習（稼働） → 時間経過で音符蓄積 → ガチャ解放
　↓
正答・成果でハートや音符追加 → 継続・再挑戦


子ども：音符を集めたい → 自然に学習・滞在

システム：動画視聴でガチャ → 自然な収益発生

→ 教育・演出・収益の三位一体ループが完成。

ポイント

形を見るだけで“どのイベントの音符か”が即わかる。

数値やバーではなく“音符で進行を表す”。

同一画面で複数種類は出さない（集中を壊さない設計）。

効果音：学習中は「ピッ」、成果時は「ポワン」、当選時は「ドレミ～♪」。

実装定義（NOTE_KIND）
// scene → note glyph & color

  active:    { glyph: "♫", color: "#60a5fa", name: "連符" },
  study:     { glyph: "♩", color: "#f472b6", name: "四分音符" },
  challenge: { glyph: "♬", color: "#fb7185", name: "複連符" },
