# 🥊 ドレスタ／ガチャ弁 バトルシステム設計まとめ（2025-11-02）

---

## 🎮 基本コンセプト

> **「勉強のバトルを、音のステージに変える。」**
>
> 勝ち負けではなく、**自分の音の成長**を感じる仕組み。
> 問題を解くたびに“音”が鳴り、努力が“音楽”として積み重なる。
> バトルは「努力＝音」「続練＝ハーモニー」「挑戦＝ライブステージ」として表現。

---

## ⚙️ バトルの流れ

1. 🎟 **バトル券一枚で 7 問挑戦**

   * CPUとの1対1バトル（同じ問題で勝負）
   * 正答数で勝敗が決まる
   * 正答するたびに「ドレミ音符」が点灯

2. 🎯 **スコア集計**

   * 自分とCPUの正解数を比較
   * 同点は「延長戦」へ移行

3. 🌿 **結果画面 (BattleResultPage)**

   * 正解数に応じてDP(ドレミポイント)を獲得
   * DPが増えると称号が上昇（楽器成長システム）
   * 条件に応じて広告ステージへ遷移

---

## 🎥 広告ステージ設計

| 正解数    | 種類              | 条件     | 内容              | 報酬               | 広告本数 |
| ------ | --------------- | ------ | --------------- | ---------------- | ---- |
| 0〜3問   | ―               | 半分未満   | 通常終了            | DPなし             | ―    |
| 4〜6問   | 🌀 **延長戦ステージ**  | 半分以上正解 | 広告視聴で「延長 3 問」挑戦 | 延長 3 問の正解ごとにDP加算 | ✅ 1本 |
| 7問全問正解 | 🌟 **ボーナスステージ** | パーフェクト | 広告視聴で「ごほうび問題」1問 | 正解で +5 DP        | ✅ 1本 |
| 不正解時   | ❤️ **救済広告**     | 問題ごと   | 広告視聴で続きから再開     | ―                | ✅ 1本 |

---

## 💰 DP(ドレミポイント)報酬

| 状況     | DP加算           |
| ------ | -------------- |
| 4問正解   | +2             |
| 5問正解   | +5             |
| 6問正解   | +7             |
| 7問全問正解 | +10（ボーナス問題で+5） |
| 延長戦    | 1問ごと+2～3       |
| 救済広告   | DP変化なし         |
