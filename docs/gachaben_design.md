## 2. 学習システム（❤制）
- ❤最大：5
- 問題を解くごとに ❤−1
- ❤回復方法：
  - 15分ごとに1回復
  - 広告視聴で全回復（MAX5まで）

## 3. ミッションとガチャ
### デイリーミッション
1. 教科書問題（1ステージ＝5問、全問正解でクリア）
2. プレイ時間5分以上
3. 計算・漢字・音読（いずれか1回でクリア）

### ガチャの種類
- ①1つずつクリア → **ノーマルガチャ**（B中心、A：5%、S：1%）
- ②2つずつクリア → **激熱ガチャ**（A中心、S：10%）
- ③3つずつクリア → **プレミアムガチャ**（S確定）

### ガチャ追加
- ガチャ後、**広告視聴で同レベル＋1回**おかわり可能（回数制限は後日調整）。

#🧭 全体コンセプト

勉強を“バトル”として楽しむ。
相手と戦うのではなく、自分の努力と知識を積み上げて「ドレミファソラシド」を完成させる。
カード戦略・学年別出題・音符演出で、学習と達成感を一体化。

⚔️ バトルの基本構造
要素	内容
対戦相手	コンピュータ（AI出題）※競争ではなく挑戦型
勝利条件	**ドレミファソラシド（7ポイント）**を集める
出題形式	プレイヤーが問題Lv（1〜3）を選択して挑戦
出題範囲	プレイヤーの学年・学習単元に基づく問題
使用カード	最大3回まで使用可能（戦略要素）
ミス時の救済	広告視聴 or 復活カードでコンボ維持
音符演出	正解時に♪点灯・音階上昇、満タンで勝利演出
🧮 出題ルールとポイント
レベル	難易度	成功時	失敗時
Lv1	基礎（安全）	+1ポイント	コンボリセット
Lv2	標準（中リスク）	+2ポイント	コンボリセット
Lv3	応用（高リスク）	+3ポイント	コンボリセット

※音符は7段階（ド→レ→ミ→ファ→ソ→ラ→シ→ド）で進行。
※Lv選択とカードの組み合わせでプレイスタイルが変化。

🎴 カードシステム（戦略要素）
カード名	効果	タイミング	備考
🧠 選択肢カットカード	選択肢が1つ減る（4択→3択）	出題前	難問対策
❤️ 復活カード	ミスしてもコンボ維持（1回限り）	自動発動	広告と共通効果
🌟 スタートブーストカード	開始時に+2ポイント（ミ→ファから開始）	開始時	連続挑戦報酬など
⏰ 時間延長カード	制限時間+5秒	出題直後	Lv2/Lv3で有効
🔄 チェンジカード	出題された問題を変更	出題後	ランダムで再抽選

🪄 使用ルール：

各バトルで 最大3回まで使用可能（usedCards ≤ 3）

所持カードは常時画面下に表示

使用済カードは半透明・使用回数カウント表示

「復活カード」は自動発動のため使用回数に含まない

🧠 出題ロジック（学年・単元連動）

初回登録時に user.grade を保存（例：3年生）

Firestoreの problems コレクションを学年＋単元で絞り込み

user.progress で現在の学習単元を管理

## 6. ランキングイベント（週末）
- **週次イベント**：月〜日で1サイクル。
- **平日**：その**日**に解いた問題のみが武器。
- **週末（土日）**：その**週**に解いた全問題が武器、**ポイント2倍**。
- 勝敗ポイント（例）：
  - 勝利：+30
  - 惜敗：+10
  - 敗北：+5
  - 引き分け：+1

### 報酬設計
- 1位：プレミアムガチャ券×5 ＋ 特別称号
- 2位：プレミアムガチャ券×3
- 3位：プレミアムガチャ券×2
- 上位1割：プレミアムガチャ券×1 ＋ 称号
- 参加賞（全員）：ノーマルガチャ券×1
- ※称号の中身は後日定義（期間限定 or 累積型）。

10. 用語定義（ブレ防止）

❤：スタミナ。最大5。内部キー hearts。

バトル券：1日の無料挑戦回数。内部キー battleTickets（最大3）。

武器：ユーザーが解いた問題IDの集合。バトル出題の母集団。

問題レベル：level = 1/2/3（難→重みづけに使用）。

週：月曜00:00〜日曜23:59（Asia/Tokyo）。

11. クリティカル仕様（境界条件）

❤消費タイミング：問題の「解答確定」時に -1。

❤回復タイミング：lastHeartTick から 15分ごとに +1（MAX=5）。

広告回復：視聴完了イベント受信時に hearts=5。連打防止にクールダウン 10分。

直近出題クールタイム：同一問題は同セッションで連続出題禁止＋週末イベント中は同問題の再出現間隔=3問以上。

未成年配慮：広告はミュート解除不可・スキップ不可のリワード広告のみ。ペアレンタル同意（ToS/Privacyに明記）。

13. バトル出題ロジック（確定アルゴリズム）

武器母集団＝users/{uid}.solvedProblems。

バトルガチャ結果（80/50/30）→重みテーブルを選択。

weightedRandomPick(母集団, weights[level]) で1問選ぶ。

直前出題と同一IDはスキップ。

CPU正誤は「相手履歴の正答率×問題level×乱数」で判定（係数は環境変数で可変）。

❤自動回復（クライアント共通関数）

export function computeHearts(now, lastTick, hearts) {
  if (hearts >= 5) return { hearts, lastTick };
  const minutes = Math.floor((now - lastTick) / 60000);
  const gained = Math.floor(minutes / 15);
  if (gained <= 0) return { hearts, lastTick };
  const nextHearts = Math.min(5, hearts + gained);
  const consumedMinutes = gained * 15;
  const nextTick = lastTick + consumedMinutes * 60000;
  return { hearts: nextHearts, lastTick: nextTick };
}

function pickProblem(pool, weights, recentIds) {
  const candidates = pool.filter(p => !recentIds.includes(p.id));
  return weightedRandom(candidates, p => weights[p.level]);
}
