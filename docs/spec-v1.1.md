🧭 1. 基本コンセプト

「勉強＝ガチャ＋バトル＋育成」で楽しく続ける学習アプリ。

学習 → ガチャ → 強化 → バトル のループで習慣化。
広告視聴によるリワード設計で、自然な収益モデルを構築。

v1.4では、“敵を倒す戦い”から“音で努力を奏でる体験”へ進化。
「ドレミファソラシド」を集める新・努力型バトルを軸に統一。

⚔️ 2. 新バトルシステム「ドレミチャレンジバトル」
概要

対戦相手：CPU（挑戦型、非競争）

勝利条件：**ドレミファソラシド（7ポイント）**を集める

出題形式：Lv1〜Lv3（プレイヤー選択式）

出題範囲：ユーザーの学年・進度に応じた問題をFirestoreから取得

カード：1試合につき最大3回まで使用可能

ミス救済：広告 or 復活カード

音符演出：正解で1音ずつ進行。7音達成で勝利＆祝福演出。

🧮 出題ルールとポイント
レベル	難易度	成功時	失敗時
Lv1	基礎（安全）	+1ポイント	コンボリセット
Lv2	標準（中リスク）	+2ポイント	コンボリセット
Lv3	応用（高リスク）	+3ポイント	コンボリセット

※ 7ポイント＝ドレミファソラシド達成。勝利扱い。

🎴 カードシステム（戦略要素）
カード名	効果	タイミング	備考
🧠 選択肢カットカード	選択肢を1つ減らす（4択→3択）	出題前	難問対策
❤️ 復活カード	ミスしてもコンボ維持（自動発動）	自動	広告と共通効果
🌟 スタートブースト	開始時+2pt（ミ→ファから開始）	開始時	連続挑戦報酬
⏰ 時間延長カード	制限時間+5秒	出題直後	Lv2/Lv3有効
🔄 チェンジカード	出題を再抽選	出題後	ランダム再出題

ルール：

1バトルあたり最大3回まで使用可能

復活カードは使用回数に含めない（自動）

使用済カードは半透明化＋カウント表示

手札UIに常時表示（CardBarコンポーネント）

🧠 出題ロジック（Firestore連動）
const q = query(
  collection(db, "problems"),
  where("grade", "<=", user.grade),
  where("unit", "in", user.progress.math.completedUnits),
  where("level", "==", selectedLevel)
);


→ 学年・進度・選択Lvに基づく動的出題。
→ 後に「教科別・単元別チャレンジ」へ拡張予定。

🎵 3. ドレミポイント（努力スコア）

競争ではなく、「努力の音符」を可視化する新スコア。

行動	Doremiポイント
Lv1正解	+10
Lv2正解	+20
Lv3正解	+30
7音完成（勝利）	+50
復活使用	+5
カード未使用でクリア	+10

Firestoreの
users/{uid}/stats.doremiPoints に累積保存。

🌈 5. 音符統一システム（v1.3継承＋強化）

ログイン、稼働、問題正解、報酬演出すべてに共通。
「色 × 形 × 音」で進行を伝えるUI。

シーン	音符形	色	意味	演出
ログイン	♪（八分音符）	金・橙	1日の起点	“ふわっ”出現、ガチャ導線
稼働時間	♫（連符）	青・緑	継続・滞在	5分ごとに1音、最大7段階
学習問題	♩（四分音符）	ピンク	努力・成果	正答時ピコン演出
チャレンジ問題	♬（複連符）	赤・橙	高難度成果	“パッ”と複数舞う
プレミア当選	𝄞＋虹色音符	虹	確定報酬	ドレミ音＋虹演出
