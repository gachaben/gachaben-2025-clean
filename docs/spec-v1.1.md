# ガチャ弁アプリ構想ドキュメント v1.2（2025-10-06改訂）

> ⚠️ このドキュメントが唯一の基準仕様です。以降の企画・開発・Gitタグはこの内容に基づきます。

---

## 1. 基本コンセプト

* 「勉強＝ガチャ＋バトル＋育成」で楽しく続ける学習アプリ。
* 学習→ガチャ→強化→バトル のループで習慣化。
* **広告収益モデル重視**（課金要素は最小限）。
* ストーリーは軽い導入演出のみに留め、主軸は「3本柱」で構成。

---

## 2. 学習の三本柱

| 柱         | 内容               | 主な報酬         |
| --------- | ---------------- | ------------ |
| ① 学習問題    | 教科書に沿った基礎問題      | ❤回復、ノーマルガチャ券 |
| ② チャレンジ問題 | 難問やスピード形式、報酬倍率UP | ガチャ券＋バトルカード  |
| ③ バトル問題   | CPU対戦（ジャンケン→出題）  | ポイント、称号、壁紙   |

---

## 3. ハート（❤）システム

* 最大5個
* 問題1問ごとに −1
* 10分で +1 自動回復
* 広告視聴で全回復（MAX5）

---

## 4. ログイン・時間ボーナス

| 条件        | 報酬                  |
| --------- | ------------------- |
| 5日連続ログイン  | Sランクガチャ確定           |
| 7日連続ログイン  | プレミアムガチャ確定          |
| 1日5分プレイ達成 | シリーズ別壁紙ガチャ（昆虫・パンなど） |

> 💡 壁紙はシリーズごとに色違い／季節違いを用意。集めることで「ホーム画面演出」が変化。

---

## 5. ガチャシステム

* 通常確率：当たり20％、ハズレ80％
* 広告視聴ガチャ：当たり50％
* 5連続ハズレ後：次は確定当たり（天井演出あり）
* ガチャ実行時、「激アツ」「超激アツ」などの確率演出をランダム表示
  （例：激アツ→50％、超激アツ→60％、通常→20％）

---

## 6. バトルカード（攻守兼用・5種）

| カード名    | 攻撃時効果    | 防御時効果       |
| ------- | -------- | ----------- |
| 知略カード   | 選択肢を1つ消す | 相手の選択肢を1つ追加 |
| スピードカード | タイマー短縮   | タイマー延長      |
| 安定カード   | 攻撃安定＋1   | ダメージ軽減      |
| ブーストカード | 報酬×2     | 被ダメージ半減     |
| リトライカード | 再挑戦可     | 再挑戦不可を解除    |

> 合計10パターンの戦略性。バトル時にランダム3枚提示→1枚選択制。

---

## 7. バトルシステム（ジャンケン＋出題）

1. ジャンケン勝者が先攻（攻撃側）
2. 攻撃時に「かけPW」→ 問題出題
3. 正解すれば相手PWを削る
4. 3問先取で勝利
5. CPUは過去の平均正答率を参照して行動
6. 勝利でBpt相当の経験値＋壁紙ピース獲得

---

## 8. 広告導線まとめ

| タイミング   | 効果      | 広告タイプ  |
| ------- | ------- | ------ |
| ❤ゼロ時    | 全回復     | リワード広告 |
| ガチャ後    | もう1回引ける | リワード広告 |
| バトル券ゼロ時 | 3枚全回復   | リワード広告 |
| ログイン報酬後 | 確率UP演出  | リワード広告 |

> 広告視聴回数が多いほどガチャ率UP・壁紙アンロックも促進。

---

## 9. アイテムカードと進化

* ランク：B / A / S / プレミアム
* 進化段階：優 → 王 → 極 → 龍 → 神（5段階）
* 表示：カード下部に🥊攻撃力／💪防御力を🔥段階で表示
* Firestore上では `userItemPowers` で管理

---

## 10. イベント・ランキング

* 成績によって称号授与（例：神・極・龍・王・優）
* プレミアカード使用時は獲得ポイント倍率UP
